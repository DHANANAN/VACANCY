# VACANCY (Game Prototype)
*A psychological horror game about loneliness, withdrawal, and the version of you that made it back.*

## Bootstrapped Components:
- **`scenes/levels/prologue_hallway.tscn`**: Starter level (Prologue hallway with warm kettle, front door, moody volumetric lighting).
- **`scripts/player.gd`**: First-person controller with the **Right-Turn Lock (Cervical Collar)** mechanic.
- **`scripts/interactable.gd` & `scripts/interaction_ray.gd`**: Inspect and interact system (`[E]`).
- **`scripts/props/interactive_door.gd`**: Interactive door that swings on hinges.
- **`scripts/props/inspectable_object.gd`**: Narrative interaction (e.g. examining the kettle).

## How to Run:
1. Download **Godot 4.3 (Standard)** from https://godotengine.org/download/windows/.
2. Extract and launch `Godot_v4.3-stable_win64.exe`.
3. In the Godot Project Manager, click **Import**.
4. Browse to this directory: `C:\Users\Pc\.gemini\antigravity\scratch\vacancy-game` and select `project.godot`.
5. Click **Import & Edit**.
6. Press **F5** (or click the Play button in the top right) to launch and test!
